# UI Context — 화면·문구·상태

> 문서 역할: UI 문자열의 화면·사용자 상태·기술 맥락과 실제 검증을 기록  
> 적용 범위: 앱/웹/게임 UI 번역  
> 문서 상태: SKELETON  
> 기준 근거: `UNKNOWN` (원본 조사 후 기록)  
> 최종 갱신: 미기록

## B. 화면·문구 인덱스

|---|---|---|---|---|---|---|---|

## C. 문구 유형별 번역 기준
버튼/레이블/상태/오류/도움말을 구분한다. 사용자의 행동과 시스템 상태를 혼동하지 않는다.

## D. 기술·접근성
변수·태그·복수형·성별·접근성 레이블/읽기 순서·글자수 제한은 확인된 실제 사양만 기록한다.

## E. 실제 검증
화면·기기·버전·텍스트 넘침 여부 및 테스트 증거를 [QA 로그](../operations/QA_LOG.md)에 연결한다. 테스트하지 않았다면 `NOT_TESTED`로 둔다.

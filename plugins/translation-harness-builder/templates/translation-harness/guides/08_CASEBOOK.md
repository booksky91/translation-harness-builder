# 08 — Translation Casebook

> 문서 역할: 실제 오류·모호성·해결 근거와 재사용 조건을 축적하는 사례집  
> 적용 범위: 실제 확인된 사례가 있을 때만 활성화  
> 문서 상태: SKELETON  
> 기준 근거: `UNKNOWN` (원본 조사 후 기록)  
> 최종 갱신: 미기록

## 사용 규칙
사례는 **실제 원본 ID 또는 QA 기록**에 근거할 때만 공식 등록한다. 가상 예시는 운영 사례와 구별한다.

## 사례 인덱스
| case_id | source/unit | 문제 유형 | 결정·상태 | 상세 절 |
|---|---|---|---|---|

## 새로운 사례 작성 양식 (공식 사례 아님)
- `case_id` / 사례명:
- 원문 ID·버전·장면/화면:
- 확인된 원문 사실:
- 처음 제안·문제의 원인:
- 수정 후보와 선택 이유:
- 사용 조건·반례·재발 방지:
- 참조 가이드·용어·상세 문서 앵커:
- QA/결정 ID·승인 상태:

현재 등록된 실제 사례: **없음(미조사)**.

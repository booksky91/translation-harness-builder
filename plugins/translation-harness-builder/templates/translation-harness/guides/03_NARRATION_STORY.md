# 03 — Narration and Information Disclosure

> 문서 역할: 서술자·시점·시간·분기·스포일러 공개 조건을 판단하는 공통 방법  
> 적용 범위: 서사/장면/분기가 의미에 영향을 주는 번역  
> 문서 상태: SKELETON  
> 기준 근거: `UNKNOWN` (원본 조사 후 기록)  
> 최종 갱신: 미기록

## A. 서술 주체 분리
서술자, 인용 화자, 관찰자, 등장인물의 추측을 구분한다. 미상 화자를 특정 인물로 확정하지 않는다.

## B. 진술 신뢰 상태
직접 관찰 / 전언 / 소문 / 기억 / 추정 / 거짓말 / 아직 검증되지 않은 서술을 구분한다.

## C. 시간·루트 격리
현재 원본의 장면 ID·시점·분기 조건을 확인한다. 다른 루트나 미래의 정보를 현재 장면의 사실로 소급하지 않는다.

## D. 정보 공개 시점
[스토리 인덱스](../story/STORY_BIBLE.md) → 현재 [장면군 양식](../story/arcs/_ARC_TEMPLATE.md)에서 복제한 실제 카드 → [정보 공개표](../story/TIMELINE_AND_REVEALS.md)를 확인한다.

## E. 표현 지침
의도적 모호성, 대명사, 시간 관계, 회상/독백을 원문 근거 없이 명확화하지 않는다.

## F. QA
원본 파일 순서를 이야기의 실제 시간 순서로 가정하지 않는다. 새 사실은 해당 장면·화자에게 허용된 시점에서만 번역에 반영한다.

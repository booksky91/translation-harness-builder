# Harness Change History

> 문서 역할: 문서·정책·근거 변경과 영향받는 자산·번역 단위를 추적  
> 적용 범위: 하네스 모든 개정  
> 문서 상태: SKELETON  
> 기준 근거: `UNKNOWN` (원본 조사 후 기록)  
> 최종 갱신: 미기록

## 변경 기록
| 변경 ID/일자 | 변경 자산·절 | 이전 → 현재 | 원인·원본·결정 ID | 영향받는 참조/단위 | 재검증 |
|---|---|---|---|---|---|

## 변경 처리 순서
1. 새 원본/정책/검수 결과를 확인한다.
2. 단일 기준 문서(용어집·인물 상세·스토리 상세·결정 원장 등)를 갱신한다.
3. 상위 인덱스와 교차 링크·프로젝트 Rule의 경로를 확인한다.
4. 영향을 받는 기존 번역을 찾아 재검수한다.
5. 변경 기록과 남은 미확정 사항을 작성한다.

## 보존 원칙
기존 승인·결정·출처를 이유 없이 삭제하지 않는다. 문서를 이동·분할하면 기존 ID와 링크를 유지하거나 명시적인 이전 정보를 남긴다.

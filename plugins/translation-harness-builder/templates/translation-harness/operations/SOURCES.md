# Source Register — 원본·근거 등록부

> 문서 역할: 원본 파일, 접근 범위, 실제 열람한 단위와 근거 ID를 관리  
> 적용 범위: 프로젝트 모든 원본·참고 자료  
> 문서 상태: SKELETON  
> 기준 근거: `UNKNOWN` (원본 조사 후 기록)  
> 최종 갱신: 미기록

## 1. 조사 가능 범위
접근 가능한 원본/번역본/화면/오디오, 제외된 자료, 아직 열지 못한 범위와 버전을 기록한다.

## 2. 소스 인벤토리
| source_id | 파일/경로 | 형식·언어 | 제공자 | 버전/날짜 | 실제 확인 범위 | 접근·신뢰 상태 |
|---|---|---|---|---|---|---|

## 3. 단위 식별 규칙
원본 ID가 있으면 그대로 유지한다. 없다면 경로+버전+행/장면/타임코드로 재식별 가능한 **임시 ID**를 만들고 임시값임을 명시한다.

## 4. 근거 기록
| evidence_id | source_id | unit_id/위치 | 실제 관찰 | 확인 방법 | 연결 자산 |
|---|---|---|---|---|---|

## 5. 보안·저작권
필요 이상의 원문 장문·비밀값·개인정보를 하네스에 복사하지 않는다. 인용이 필요한 경우 위치와 최소 구절만 적는다.

## 6. 새 버전 수용
변경/이동된 소스 ID를 매핑하고 영향받는 상세 문서·번역 단위·결정·QA를 식별한다. 열어보지 않은 자료를 검증 완료로 표시하지 않는다.
